# Linux Lab Projects

A collection of hands-on Linux administration and troubleshooting projects.

## Projects

### 1. Backup Script
**Location:** `backup-script/`

A Bash script for practicing file backup and Linux command-line operations.

### 2. Log Parser
**Location:** `log-parser/`

A Bash script that reads a log file and parses matching lines. Includes a sample log for testing.

### 3. System Health Report
**Location:** `system-health-report/`

A Bash script that gathers system diagnostic information and generates a health report.

## Skills Practiced

- Bash scripting
- Linux command-line tools
- File operations and backups
- Log analysis
- System diagnostics and troubleshooting

## Disclaimer

These are personal learning projects intended for practice and demonstration.
